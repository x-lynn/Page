# UniTask 项目代码说明

## 项目概述

根据设计文档，我已经完成了完整的 UniTask 个人任务管理应用的代码实现。项目采用模块化、组件化的设计，代码结构清晰，易于维护和扩展。

## 代码特点

### 1. 封装设计

- **工具函数层** (`utils/`): 所有通用功能都封装在工具函数中
  - `supabase.js`: Supabase 客户端初始化和认证管理
  - `settings.js`: 环境变量和配置管理
  - `constants.js`: 应用常量定义（任务类型、状态、优先级等）
  - `helpers.js`: 通用工具函数（日期格式化、防抖、节流等）

- **状态管理** (`stores/`): 使用 Pinia 进行状态管理
  - `tasks.js`: 任务相关的所有状态和操作
  - `user.js`: 用户相关的状态和操作
  - 所有数据操作都封装在 store 中，页面组件只需调用方法

- **UI 组件** (`components/`): 可复用的 UI 组件
  - `TaskCard.vue`: 任务卡片组件
  - `PriorityBadge.vue`: 优先级标签组件
  - `StatusBadge.vue`: 状态标签组件
  - `FilterModal.vue`: 筛选弹窗组件
  - `SettingsForm.vue`: 设置表单组件

### 2. 代码简洁性

- 使用 Vue 3 Composition API 和 `<script setup>` 语法，代码更简洁
- 统一的样式系统 (`styles/common.scss`)，避免重复代码
- 组件职责单一，易于理解和维护
- 统一的错误处理和用户提示

### 3. UI 设计

- **现代化设计**: 采用卡片式布局，圆角、阴影等现代设计元素
- **响应式交互**: 按钮点击、卡片点击都有视觉反馈
- **颜色系统**: 统一的主题颜色，优先级和状态都有对应的颜色标识
- **空状态处理**: 友好的空状态提示
- **加载状态**: 清晰的加载提示

## 核心功能实现

### 1. 用户认证
- 应用启动时自动进行匿名登录
- 用户身份持久化存储在设备本地
- 所有数据操作都需要认证

### 2. 任务管理
- 支持标准任务和每日任务两种类型
- 任务状态：待办、进行中、已完成
- 任务优先级：低、中、高
- 支持任务筛选和排序
- 支持任务归档

### 3. 每日任务
- 独立的每日任务视图
- 支持手动重置每日任务状态
- 未来可扩展自动重置功能

### 4. 用户设置
- 用户昵称设置
- Showdoc 推送链接配置
- 任务统计信息展示

## 使用说明

### 1. 安装依赖

```bash
npm install
```

### 2. 配置环境变量

创建 `.env` 文件（参考 `.env.example`）：

```
VUE_APP_SUPABASE_URL=your_supabase_url
VUE_APP_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 3. 初始化数据库

在 Supabase 控制台的 SQL Editor 中执行 `database/init.sql` 文件。

### 4. 运行项目

```bash
# H5 开发
npm run dev:h5

# 微信小程序开发
npm run dev:mp-weixin
```

## 代码亮点

1. **类型安全**: 使用常量定义任务类型、状态、优先级，避免硬编码
2. **错误处理**: 统一的错误处理和用户提示
3. **性能优化**: 使用防抖、节流等优化用户体验
4. **可扩展性**: 模块化设计，易于添加新功能
5. **代码复用**: 组件化设计，减少重复代码

## 注意事项

1. **TabBar 图标**: 需要在 `static/tabbar/` 目录下添加对应的图标文件
2. **环境变量**: 确保正确配置 Supabase 环境变量
3. **数据库**: 确保在 Supabase 中正确执行了初始化 SQL
4. **RLS 策略**: 确保数据库的 RLS 策略正确配置，保证数据安全
